# حساب الفلوس 💰

واجهة بسيطة لحساب فلوسك بالدرهم.

## شنو فيها؟

- **عد الفلوس:** غير 200 و100 درهم، بزرار + و−، والمبلغ الإجمالي كيبان كبير فوق.
- **فلوسي مقسّمة:** 3 خانات بسيطة — الأساسي، اللي كنستعملو وكنصرف منو، والسلف.
- **شحال كنسال الناس:** لائحة بالأسماء والمبالغ — واش الشخص كيسالك ولا كتسالو — مع مجموع كل جهة.

بلا قطع نقدية، بلا تعقيد. المعطيات كتبقى غير في جهازك، ويشتغل بلا أنترنيت.

صنع للمغاربة 🇲🇦
