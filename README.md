# حساب الفلوس

واجهة كبيرة وبسيطة، بالرمادي والأبيض فقط.

## شنو فيها؟

- **مجموع المال اللي عندي:** خانة كبيرة كتكتب فيها المبلغ الكامل.
- **فلوسي مقسّمة:** الأساسي، اللي كنستعملو وكنصرف منو، والسلف.
- **شحال كنسال الناس:** لائحة بالأسماء والمبالغ — كيسالني ولا كنسالو — مع مجموع كل جهة.

بلا أوراق، بلا قطع نقدية، بلا ألوان. المعطيات كتبقى غير في جهازك، ويشتغل بلا أنترنيت.
