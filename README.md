# حساب الفلوس

واجهة داكنة على شكل تطبيق بنكي: الرصيد كبير في الوسط، أزرار دائرية، والمعاملات كقائمة.

## شنو فيها؟

- **الرصيد:** مجموع المال اللي عندي، مع زر العين لإخفاء/إظهار المبلغ.
- **المعاملات:** الاقتطاعات كقائمة معاملات (الاسم، التاريخ، -المبلغ)، مع كتنقص والباقي فوق.
- **فلوسي مقسّمة:** الأساسي، كنصرف منو، السلف.
- **كنسال الناس:** كيسالني ولا كنسالو، مع المجموعين.

المعطيات كتبقى غير في جهازك، ويشتغل بلا أنترنيت.
